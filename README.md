# 🏠 Meine Wohnung

Zentrale Sammlung für alles rund ums Wohnen: Projekte, Räume, Verträge, Kontakte, Wartung und Ideen.

## Struktur

| Ordner / Datei | Inhalt |
|---|---|
| [`wohnung.md`](wohnung.md) | Steckbrief: Eckdaten, Grundriss, Maße, Zählernummern |
| [`projekte/`](projekte/) | Anstehende und laufende Projekte (je eine Datei pro Projekt) |
| [`raeume/`](raeume/) | Pro Raum: Maße, Ausstattung, Wünsche, offene Punkte |
| [`dokumente/`](dokumente/) | Verträge, Versicherungen, Nebenkosten, Rechnungen (Übersicht) |
| [`einkauf/`](einkauf/) | Wunschliste & Einkaufsliste für die Wohnung |
| [`kontakte/`](kontakte/) | Vermieter, Hausverwaltung, Handwerker, Notfallnummern |
| [`wartung.md`](wartung.md) | Wiederkehrende Aufgaben (Filter, Entkalken, Zählerstände …) |
| [`ideen.md`](ideen.md) | Lose Ideen & Inspiration, bevor sie zu Projekten werden |
